# Phasma v0.6.0

This is the first public release of Phasma, a modular ESP library for Roblox executors.

## Highlights

- Ten independent elements: Box, Name, Distance, Health, Tracer, Skeleton, HeadDot, Highlight, Direction and Arrow.
- Drawing API and ScreenGui backends behind one object surface.
- Time-based entrance and exit animations with separate channels for fade, pop, slide, sweep, tracer and arrow.
- Tracer that draws from its origin with a glow line and a travelling spark.
- Edge arrows with a distance label, including a behind-camera fallback.
- Filters, distance-based level of detail, object ESP and seven named presets.
- Security defaults for overlay names, GUI protection and Highlight placement.

## Installation

Executor, single file:

```lua
local Phasma = loadstring(game:HttpGet("https://github.com/Saint0-0/Phasma/releases/latest/download/Phasma.luau"))()
```

Model:

Download `Phasma.rbxm` from this release, place the `Phasma` folder in `ReplicatedStorage`, and require `Phasma.Init`.

## Assets

- `Phasma.luau`: the bundled and minified library for executors.
- `Phasma.rbxm`: a Roblox model that contains the same bundle as a ModuleScript.
