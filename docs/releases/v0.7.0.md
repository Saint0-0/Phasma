# Phasma v0.7.0

This release adds single-target focus, so a script can draw the ESP for one chosen target and change that target at runtime.

## Highlights

- `esp:SetTarget(instance)` limits the ESP to one target and hides every other candidate.
- `esp:ClearTarget()` returns to the normal target list, and `esp:GetTarget()` returns the current target.
- `Focus.Target` is a live setting, so the target can also be assigned through `esp.Settings.Focus.Target`.
- A Player target follows the character through a respawn.
- A Humanoid or a body part of a character resolves to that character.
- A Model or BasePart without a humanoid rig uses the object element set.
- Focus bypasses filters, distance cutoffs, level of detail and the visibility check for the chosen target.
- Object focus forces the edge arrow on, so the target remains reachable when it leaves the viewport.
- Changing the target fades the previous entry out and the new one in through the normal animation path.

## Example

```lua
local Phasma = loadstring(game:HttpGet("https://github.com/Saint0-0/Phasma/releases/latest/download/Phasma.luau"))()

local esp = Phasma:CreateESP({
	MaxDistance = 1000,
})

-- Track an autofarm destination and change it as the route advances.
esp:SetTarget(workspace:WaitForChild("Bandit"))
esp:SetTarget(workspace:WaitForChild("Chest"))

-- Return to the normal target list.
esp:ClearTarget()
```

## Assets

- `Phasma.luau`: the bundled and minified library for executors.
- `Phasma.rbxm`: a Roblox model that contains the same bundle as a ModuleScript.
