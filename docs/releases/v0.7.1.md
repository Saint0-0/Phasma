# Phasma v0.7.1

This release aligns the renderer with Studio. Every client now uses the ScreenGui path, so box styles and the other elements look the same on an executor as they do in the test place.

## Highlights

- Removed the executor Drawing path. Phasma no longer checks for `Drawing.new`, and `Phasma.Canvas.new` always returns the ScreenGui canvas.
- `Box.Style` now behaves identically everywhere, including `"Corners"` and `"Both"`.
- `esp.Canvas.Kind` is always `"Gui"`, which keeps diagnostics stable.
- The ScreenGui overlay still prefers `gethui()`, calls `protectgui` or `syn.protect_gui` when available, and randomises names through `Security`.
- Removed `Constants.DrawingFont`, which only the Drawing path used.

## Example

```lua
local Phasma = loadstring(game:HttpGet("https://github.com/Saint0-0/Phasma/releases/latest/download/Phasma.luau"))()

local esp = Phasma:CreateESP({
	Box = { Enabled = true, Style = "Corners", Filled = true },
	Name = { Enabled = true },
	Distance = { Enabled = true },
})

-- The same corner brackets that appear in Studio now appear on the executor.
esp.Settings.Box.Style = "Both"
```

## Assets

- `Phasma.luau`: the bundled and minified library for executors.
- `Phasma.rbxm`: a Roblox model that contains the same bundle as a ModuleScript.

## Documentation

The README, API reference, configuration guide, architecture notes and changelog now describe a single rendering path. The focus API from `v0.7.0` is unchanged.
